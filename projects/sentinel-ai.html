01 / Problem

Video understanding requires space and time.

Single frames miss the dynamics of an action.

Violence detection is not only an image-classification problem. A useful system must recognize visual features within frames and how motion evolves across a sequence. SentinelAI combines a convolutional image encoder with a recurrent temporal model to analyze those two dimensions together.

Spatial

What is in each frame?

EfficientNetB0 extracts compact visual features from normalized frames.

Temporal

How does the action evolve?

A bidirectional LSTM models relationships across a 20-frame sequence.

Operational

Can inference stay fast?

The selected model balances benchmark performance with fast real-time inference.

10 / Limitations

A strong benchmark is not universal deployment evidence.

Context and responsible use still matter.

  • Results are tied to the documented 2,000-video dataset and its preprocessing pipeline.
  • Performance may change with different cameras, environments, compression, viewpoints, or kinds of motion.
  • A binary violence label cannot replace contextual human judgment.
  • Operational surveillance use would require privacy, bias, safety, and false-alarm review beyond this project benchmark.
  • The public repository documents a prototype dashboard, not a production monitoring service.
